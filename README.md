# 🌟 Minecraft Java SMP C++ Edition (v2.0 终极架构与纯正 PvP 机制重构版)

🎮 一个基于 C++ 和 OpenGL 实现的高性能精简版 Minecraft Java 多人联机/PVP 仿真游戏引擎。项目完美复刻并深度优化了高版本原版 Minecraft 的经典 PvP 战斗机制（如 1.21 重锤风爆与下落还原点、斧子破盾、跳击暴击）、高智能战术 Bot AI 以及立体体素地形渲染。

---

## 🌟 核心功能特性

### ⚔️ 深度 PvP 战斗与武器系统
- **重锤风爆弹飞与还原点机制 (Mace Wind Burst)**：精准计算下落滞空落差（`fallDist`），当玩家处于高空挥舞重锤砸中目标时，触发震撼的音效与风爆粒子，造成巨额暴击伤害，并在击中瞬间将下落点重置为新的落地还原点，强力反弹向上，完美复刻原版 1.21 机制！
- **斧子与重锤破盾机制**：盾牌可完美抵挡常规剑类伤害，但使用**下界合金斧**或**重锤**攻击正在举盾的目标时，会触发破盾效果使其盾牌失效，并施加 **5秒（100帧）的破盾冷却硬直**。
- **跳击暴击与武器平衡**：支持下落过程中的跳击暴击倍率，下界合金斧与钻石剑具备各自独立的攻击冷却频率（`maxAttackCooldown`），还原真实的连击手感。
- **血量与护盾显示**：玩家及所有 Bot 头顶上方均会实时动态渲染精致的**血量条（Health Bar）与吸收护盾**。
- **精准 AABB 实体与方块碰撞箱**：彻底重构了物理碰撞与射线检测算法，让近战砍击、走位、潜行防跌落更加精准爽快，告别幽灵刀与穿墙。

### 🤖 高智能战术 Bot AI 系统
- **动态寻敌与决策**：Bot 拥有自主决策逻辑，会自动寻找最近的敌人（包括玩家或其他 Bot）进行追击与走位拉扯。
- **吃金苹果与战术破盾**：当 Bot 血量较低时会自动寻找机会吃金苹果恢复生命与护盾；当侦测到对手举盾时，会智能切换为斧头或重锤进行破盾反击。

### 🌍 大世界与性能渲染
- **广阔立体纯方块地形**：大幅扩大的世界规模（$52 \times 20 \times 52$），通过多重数学函数叠加生成了**高低起伏、山峦叠嶂的立体地形**（草方块、泥土、石头）。
- **性能分级地形渲染**：支持通过快捷键 `T` **动态切换渲染质量等级**（高/中/低配），低配模式下自动优化视距与方块步长，确保大世界高帧率流畅运行。
- **边缘潜行防跌落**：按下 `Ctrl` 键进入潜行状态时，系统会智能检测前方悬空边缘，防止不小心跌落。
- **挖掘与放置反馈**：还原原版的方块挖掘进度条、攻击冷却进度条、吃金苹果机制以及全套音效。

## 🎮 控制说明

- **移动**：`W`, `A`, `S`, `D`
- **跳跃**：`Space`
- **潜行（防边缘跌落）**：`Ctrl`
- **疾跑**：`F`
- **切换视角（第一/第三人称）**：`F5`
- **切换性能渲染画质**：`T` （高配 / 中配 / 低配循环切换）
- **切换显示实体 AABB 碰撞箱**：`R`
- **物品栏选择**：数字键 `1 - 9`
- **攻击 / 挖掘方块**：鼠标左键
- **放置方块 / 举盾防御 / 吃金苹果（长按）**：鼠标右键
- **退出游戏**：`Esc`

## 🚀 编译与运行

本代码完全封装在单个 C++ 源文件中，依赖 `OpenGL`, `GLEW`, `WinMM` 多媒体库。

### 使用 Visual Studio 编译指南：
1. 在 Visual Studio 中创建一个新的 **C++ 空项目**。
2. 将最新代码保存为 `main.cpp` 并添加到源文件中。
3. 配置项目的附加包含目录与库目录（确保已正确配置并链接 `glew32.lib`, `opengl32.lib`, `glu32.lib`, `winmm.lib`）。
4. 将生成模式设置为 `Release`，编译并直接运行生成的可执行文件即可！
